# Grocery-Delivery-Website
GreenCart is a sleek and responsive grocery delivery web application built with React.
It allows users to explore fresh produce, view detailed product information, and shop online.
Features include dynamic product pages, image previews, add-to-cart, and secure checkout flow.
Developed using React, Context API, React Router, and Tailwind CSS for a smooth UI/UX.
Ideal for modern e-commerce platforms aiming for speed, simplicity, and scalability.
